# 产品界面设计（Stock Ontology MVP Web 工作台）

- 状态：V0.2 设计基线（Epic #29 / #30 起生效）
- 技术栈：见 [ADR-0005](adr/0005-product-ui-stack.md)
- 视觉方向：浅色技术型 Dashboard（维护者意向图只定义信息层级与视觉方向，
  不代表既有功能、真实统计、认证能力或验收数据）

## 1. 设计原则

1. **证据优先**：任何经营结论旁必须可直达 Claim ID、原文页码、时间口径、
   数据新鲜度；证据不足显示为"证据不足"，绝不渲染成否定。
2. **诚实状态**：命中/排除/未知/冲突/降级/过期全部可见；没有数据显示
   空态与原因，不用占位数字冒充真实统计。
3. **受控输入**：查询表单只暴露后端 Schema 允许的字段（Intent/枚举/
   白名单指标）；不做自由文本伪装成已可用的聊天查询。
4. **能力感知**：后端 `/readyz` 未声明的能力，导航显示"未启用"+原因，
   不放置可点击但无效的按钮。
5. **可访问为默认**：键盘可达、焦点可见、语义化标签、不仅靠颜色传达
   状态、尊重 `prefers-reduced-motion` 与 `prefers-color-scheme`。

## 2. 设计 Token（语义化，`web/src/styles/tokens.css`）

| Token 组 | 内容 |
|----------|------|
| 颜色 | `--color-bg` / `--color-surface` / `--color-border` / `--color-fg` / `--color-fg-muted` / `--color-primary` / `--color-primary-fg` / `--color-success` / `--color-warning` / `--color-danger` / `--color-info` |
| 状态语义 | success=OK/PROCESSED、warning=DEGRADED/PENDING、danger=FAIL/REJECTED、info=进行中 |
| 间距 | 8px 基数（`--space-1..12`） |
| 圆角/阴影 | `--radius-sm/md/lg`、`--shadow-card` |
| 字体 | 系统 UI 栈 + 等宽数字（`font-variant-numeric: tabular-nums`）用于金额/指标 |
| 断点 | 375 / 768 / 1024 / 1440px（无横向溢出为验收线） |

主题切换：`data-theme="light|dark"` 挂 `<html>`；默认跟随
`prefers-color-scheme`，用户选择持久化 `localStorage`。

## 4. 状态渲染规范（全应用统一）

| 状态 | 渲染 |
|------|------|
| 加载 | Skeleton（不阻塞布局跳动） |
| 空 | 空态插画/文案 + 下一步动作 |
| 错误 | 分类文案（网络/超时/权限/校验/服务端）+ 可重试 + trace_id |
| 降级 | 黄色横幅引用后端 `degradation_notes` 原文 |
| 权限 | 401/403 显示可理解拒绝；不隐藏了事，也不泄露内部细节 |
| 提交中 | 控件禁用 + 进度指示（防重复提交） |

## 5. 关键页面（V0.2 逐步交付）

- **首页 `/`**：系统状态卡（/readyz 组件+能力）、数据新鲜度、快捷查询、
  黄金查询入口、最近活动。
- **查询工作台**：结构化表单（Intent/语义过滤/财务口径）→ Grounded
  结果表 → 每行展开证据包（Claim ID / 原文 / 推理路径 / 新鲜度）。
- **图谱浏览器**：产品/概念图谱可视化 + **并列的表格替代视图**
  （图谱不是唯一信息表达）。
- **证据浏览器**：文档 → 版本 → 片段 → Claim 链路，双时态与 Provenance
  展示。
- **审核工作台**：待审 Claim 与证据并排；接受/拒绝需理由；乐观并发
  （版本/ETag）冲突提示；认证未交付前置灰。
- **运维视图**：数据源能力、采集/标准化运行、投影水位、对账、健康。

## 6. 验收基线（继承 Epic #29）

- 375/768/1024/1440px 无横向溢出；亮/暗主题全量适配。
- WCAG 2.2 AA 自动检查 + 键盘人工检查。
- 深链接刷新不 404；API 中断/恢复有可见状态。
- 无伪数据、无死按钮、无仅依赖颜色的状态。
